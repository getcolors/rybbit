Rybbit Package Skill

Deploy one Rybbit analytics server with a Python controller, private SQLite deployment state and the Hetzner CLI. PocketDeploy supplies owned infrastructure, verified SSH and recovery.

Keep it simple

One maintained Python implementation. Rybbit runs in Docker Compose with PostgreSQL, ClickHouse, Redis and Caddy. SQLite records deployment identities and operations; it does not replace the application databases.

Install and plan

npx skills add getcolors/rybbit --skill rybbit --agent codex --yes
cp .agents/skills/rybbit/rybbit ./rybbit
./rybbit validate
./rybbit plan

Install Python 3.11+, uv, OpenSSH, hcloud and the pinned Cloudflare CLI. Configuration follows the caller’s colors.yml. Keep credentials outside Git.

Deploy and recover

init prepares private local state and SSH keys. converge reconciles owned compute, DNS and application settings. prepare holds application writers and backups stopped for an explicit database restore.

PostgreSQL logical dumps and ClickHouse native backups upload to R2 under the deployment profile. Controller recovery and application-data recovery are separate. Existing infrastructure is never adopted by name.
